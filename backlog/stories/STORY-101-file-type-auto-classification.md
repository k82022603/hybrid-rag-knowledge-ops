## User Story

**As a** 시스템 운영자,
**I want** 업로드된 파일의 유형이 자동 분류되어 메모리 예산이 할당되어,
**So that** OOM 없이 안정적으로 문서를 처리할 수 있다.

---

## Acceptance Criteria

- [ ] **Given** PDF 파일이 업로드되면, **When** 유형 분류기가 분석하면, **Then** 사전형/프레젠테이션/법령집 중 하나로 분류된다
- [ ] **Given** 파일 유형이 분류되면, **When** 처리 파이프라인에 진입하면, **Then** 유형에 맞는 메모리 예산이 할당된다
- [ ] **Given** 테이블이 많은 법령집이면, **When** 메모리 예산이 할당되면, **Then** peak 메모리가 할당량을 초과하지 않는다

## 기술 노트

| 파일 유형 | 처리 속도 | 메모리 특성 |
|----------|----------|------------|
| 사전형 | 0.5min/MB | 가벼움 |
| 프레젠테이션 | 3.1min/MB | 중간, 이미지 多 |

- **리스크**: 유형 경계가 모호한 문서 (혼합형)
