# 1. 프로젝트 개요

## 목표
사내에 흩어진 지식을 **통합 검색**하고 **지능형 답변**을 제공하는 플랫폼

## 핵심 가치

| 가치 | 설명 |
|------|------|
| **지능형 검색** | Graph RAG 기반 의미 검색 + 키워드 검색 |
| **대화형 인터페이스** | 자연어로 질문하고 답변 받기 |
| **지식 관리** | 등록, 수정, 버전 관리, 메타데이터 자동 추출 |
| **개인화** | 북마크, 검색 기록, 맞춤 추천 |

# 5-1. 채팅 모드 특징

## 핵심 기능

| 기능 | 설명 |
|------|------|
| **자연어 질문** | "프로젝트 A 배포 방법 알려줘" |

## 기술 구현

- **Graph RAG**: 지식 그래프 기반 컨텍스트 검색
- **DeepSeek V3.2**: 답변 합성 LLM
- **WebSocket**: 실시간 양방향 통신
