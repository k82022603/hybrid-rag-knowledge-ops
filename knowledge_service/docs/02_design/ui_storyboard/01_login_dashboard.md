### 2.2 위젯 상세

#### 2.2.1 통계 카드

```
┌────────────────────┐
│  📚                │
│  전체 지식          │
│                    │
```

**데이터**:
- 전체 지식 수: `/api/v1/dashboard/stats`
- 오늘 등록: 당일 생성된 지식 수
- 내 지식: 로그인 사용자가 작성한 지식

## 3. 인터랙션 정의

### 3.1 헤더

| 요소 | 동작 |
|------|------|
| 로고 클릭 | 대시보드로 이동 |
| 검색창 포커스 | 최근 검색어 드롭다운 표시 |
| 검색창 Enter | 검색 페이지로 이동 |
| 알림 아이콘 | 알림 패널 표시 |
| 프로필 드롭다운 | 프로필, 설정, 로그아웃 메뉴 |

### 3.2 사이드바

| 요소 | 동작 |
|------|------|
| 메뉴 항목 클릭 | 해당 페이지로 이동 |
| 현재 페이지 | 하이라이트 표시 |
| 접기 버튼 | 사이드바 축소 (아이콘만 표시) |

### 3.3 대시보드 위젯

| 요소 | 동작 |
|------|------|
| 통계 카드 클릭 | 관련 목록 페이지로 이동 |
| 인기 지식 항목 | 지식 상세 페이지로 이동 |
| 최신 지식 항목 | 지식 상세 페이지로 이동 |
| AI 추천 항목 | 지식 상세 페이지로 이동 |
| 검색 트렌드 키워드 | 해당 키워드로 검색 |
