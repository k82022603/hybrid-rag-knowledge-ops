## 상세 검증

### 1. ELSER 라이선스 (정확함 ✅)

공식 문서에서 확인된 내용입니다. ELSER는 Platinum 이상의 구독이 필요합니다.

> "It is bundled with Elasticsearch, so they can use it out-of-the-box under a **platinum license**"  
> — Elastic 공식 문서

> "To use ELSER, you must have the **appropriate subscription level** for semantic search or the trial period activated."  
> — Elastic ELSER 문서

### 2. BGE-M3 외부 임베딩 방식 (정확함 ✅)

외부에서 생성한 벡터를 `sparse_vector` 또는 `rank_features` 필드에 저장하는 것은 Basic 라이선스에서 가능합니다. 이 필드 타입들은 라이선스 제한이 없습니다.

> "Elasticsearch initially supported sparse vector search using the rank_features query. However, with recent advancements, sparse vector search is now natively available through the sparse_vector query"  
> — Elastic Labs

### 3. RRF 라이선스 (틀림 ❌)

**이 부분이 핵심 오류입니다.** RRF는 **Platinum 이상에서만 사용 가능**합니다.

> "RRF is available as a technical preview for **Platinum+ users**"  
> — Elastic 8.9 Release Notes

> "The RRF feature in Elasticsearch is **not free**; you need a paid subscription to use it."  
> — Medium 기술 블로그

Basic 라이선스에서 RRF 사용 시 다음 오류가 발생합니다:
```
AuthorizationException(403, 'security_exception', 
'current license is non-compliant for [Reciprocal Rank Fusion (RRF)]')
```

## 수정된 전략

### Basic(무료) 라이선스에서 하이브리드 검색 구현 방법

RRF가 유료이므로, 무료 환경에서는 다음 대안을 사용해야 합니다.

#### 방법 1: Python ranx 라이브러리 사용 (권장)

```python
from ranx import fuse, Run

# Elasticsearch에서 두 검색 결과를 별도로 가져옴
bm25_results = es.search(index="my_index", query={"match": {...}})
vector_results = es.search(index="my_index", knn={...})

# Python에서 RRF 융합 수행
bm25_run = Run({"q1": {"doc1": 0.9, "doc2": 0.8, ...}})
vector_run = Run({"q1": {"doc1": 0.7, "doc3": 0.85, ...}})

fused_run = fuse(runs=[bm25_run, vector_run], method="rrf")
```

#### 방법 2: 애플리케이션 레벨 RRF 직접 구현

```python
def rrf_score(rankings: list[dict], k: int = 60) -> dict:
    """Reciprocal Rank Fusion 직접 구현"""
    scores = {}
    for ranking in rankings:
        for rank, (doc_id, _) in enumerate(ranking.items(), 1):
            if doc_id not in scores:
                scores[doc_id] = 0
            scores[doc_id] += 1.0 / (k + rank)
    return dict(sorted(scores.items(), key=lambda x: x[1], reverse=True))
```

#### 방법 3: 선형 결합 (Linear Combination)

```python
# 두 검색 점수를 정규화 후 가중 합산
final_score = alpha * bm25_score + (1 - alpha) * vector_score
```

## 수정된 라이선스 비교표

| 구분 | ELSER (공식) | BGE-M3 + ranx |
|------|-------------|---------------|
| **라이선스** | Platinum (유료) | Basic (무료) |
| **모델 관리** | ES 내부 | 외부 Python |
| **RRF** | ES 내장 (유료) | ranx 라이브러리 (무료) |
| **한국어 성능** | 영어 최적화 | 한국어 우수 |
| **인프라** | ES 리소스 점유 | 별도 추론 필요 |

## 결론

원본 내용의 핵심 전략은 올바릅니다. BGE-M3로 외부에서 벡터를 생성하여 Elasticsearch Basic에 저장하는 방식은 무료로 가능합니다. 

**단, RRF는 Platinum 기능이므로**, 무료 환경에서는 Python의 `ranx` 라이브러리나 직접 구현한 RRF 로직을 사용해야 합니다. 이 방식도 동일한 결과를 얻을 수 있으며, 오히려 가중치 조절 등 더 세밀한 제어가 가능합니다.
