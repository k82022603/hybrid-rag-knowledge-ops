## 1. 시스템 개요

### 1.1 목적

본 시스템은 사내에 분산된 프로젝트 문서, 기술 가이드, 회의록, SOP 등의 지식 자산을 통합 검색하고, 자연어 질의에 대해 맥락에 맞는 답변을 생성하는 **하이브리드 RAG(Retrieval-Augmented Generation) 기반 지식 검색 시스템**입니다.

### 1.2 핵심 기능

| 기능 | 설명 |
|------|------|
| 하이브리드 검색 | Dense + Sparse + BM25 검색 결과를 RRF로 융합 |
| 시계열 필터링 | 문서 유효기간 기반 검색 (valid_from/to) |
| 프로젝트 기반 검색 | 특정 프로젝트 범위 내 검색 |
| 관계 기반 추천 | Neo4j 그래프를 활용한 연관 지식 추천 |
| 전문가 찾기 | 특정 기술/주제에 대한 담당자 탐색 |

### 1.3 기술 스택

```
┌─────────────────────────────────────────────────┐
│                  Frontend / API                  │
├─────────────────────────────────────────────────┤
│  LangGraph Agent │ FastAPI │ Streamlit (옵션)   │
├─────────────────────────────────────────────────┤
│               Orchestration Layer                │
├─────────────────────────────────────────────────┤
│  BGE-M3 (Embedder)  │  ranx (RRF)  │  DeepSeek  │
├─────────────────────────────────────────────────┤
│                   Data Stores                    │
├───────────────┬───────────────┬─────────────────┤
│  PostgreSQL   │     Neo4j     │  Elasticsearch  │
│    (SSOT)     │   (Graph)     │    (Search)     │
└───────────────┴───────────────┴─────────────────┘
```

## 3. 임베딩 처리 흐름

### 3.1 문서 인제스트 파이프라인

```mermaid
sequenceDiagram
    autonumber
    participant U as 사용자/배치
    participant D as Docling
    participant C as HybridChunker
    participant X as DeepSeek-V3.2
    participant B as BGE-M3
    participant PG as PostgreSQL
    participant ES as Elasticsearch
    participant N4 as Neo4j

    U->>D: PDF/DOCX 업로드
    activate D
    D->>D: 문서 파싱 (테이블, 이미지 추출)
    D->>C: DoclingDocument 전달
    deactivate D

    activate C
    C->>C: 계층적 청킹 (512 tokens)
    C->>X: 청크 텍스트 전달
    deactivate C

    activate X
    X->>X: 메타데이터 추출
    Note over X: document_type, project_name,<br/>valid_dates, entities, relationships
    X-->>C: 메타데이터 JSON 반환
    deactivate X

    C->>B: 청크 텍스트 배치 전달
    activate B
    B->>B: Dense 임베딩 생성 (1024d)
    B->>B: Sparse 임베딩 생성 (token weights)
    B-->>C: Dense + Sparse 벡터 반환
    deactivate B

    par 3개 DB 동시 저장
        C->>PG: 문서 마스터 + 청크 참조 저장
        C->>ES: 청크 + 벡터 + 메타데이터 저장
        C->>N4: 지식 노드 + 관계 생성
    end

    PG-->>C: 저장 완료
    ES-->>C: 인덱싱 완료
    N4-->>C: 그래프 생성 완료

    C-->>U: 인제스트 완료 (chunk_count, document_id)
```

## 4. 검색(Retriever) 처리 흐름

### 4.1 하이브리드 검색 시퀀스

```mermaid
sequenceDiagram
    autonumber
    participant U as 사용자
    participant A as LangGraph Agent
    participant QP as Query Planner
    participant B as BGE-M3
    participant ES as Elasticsearch
    participant RRF as ranx RRF
    participant N4 as Neo4j
    participant LLM as GPT-4o / DeepSeek

    U->>A: "Alpha 프로젝트에서 React 관련 기술 가이드 찾아줘"
    
    A->>QP: 쿼리 분석 요청
    activate QP
    QP->>QP: 의도 파악 + 필터 추출
    Note over QP: project_filter: "Alpha"<br/>search_type: "hybrid"
    QP-->>A: 검색 계획 반환
    deactivate QP

    A->>B: 쿼리 임베딩 요청
    activate B
    B-->>A: Dense(1024d) + Sparse(tokens)
    deactivate B

    par 병렬 검색 실행
        A->>ES: Dense Search (kNN + filter)
        A->>ES: Sparse Search (query_vector + filter)
    end

    ES-->>A: Dense 결과 (top 20)
    ES-->>A: Sparse 결과 (top 20)

    A->>RRF: 두 결과 융합 요청
    activate RRF
    RRF->>RRF: Weighted RRF (k=60)
    Note over RRF: dense_weight: 0.6<br/>sparse_weight: 0.4
    RRF-->>A: 융합된 top 10 결과
    deactivate RRF

    opt 관계 확장 (선택적)
        A->>N4: 연관 지식 조회
        N4-->>A: 관련 문서 2-3개
    end

    A->>LLM: 컨텍스트 + 쿼리 전달
    activate LLM
    LLM->>LLM: 답변 생성
    LLM-->>A: 생성된 답변
    deactivate LLM

    A-->>U: 최종 응답 + 출처 표시
```

#### 시스템 처리 과정

```yaml
Query Analysis:
  intent: expert_finding
  technology: "Neo4j"
  action: find_experts

Neo4j Query:
  MATCH (p:Person)-[:CREATED|REVIEWED]->(k:Knowledge)-[:USES]->(t:Technology {name: "Neo4j"})
  WITH p, count(k) as doc_count
  RETURN p.name, p.department, doc_count
  ORDER BY doc_count DESC
  LIMIT 5
```

```yaml
Query Analysis:
  intent: related_knowledge

Neo4j Query:
  MATCH (k:Knowledge {title: "마이크로서비스 아키텍처"})

  WHERE related <> k
  RETURN related, relationships(path)
  LIMIT 10
```

## 부록: 용어 정의

| 용어 | 정의 |
|------|------|
| Dense Vector | 1024차원 연속 벡터, 의미적 유사성 표현 |
