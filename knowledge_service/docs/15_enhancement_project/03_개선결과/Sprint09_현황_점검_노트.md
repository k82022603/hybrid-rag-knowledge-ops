## 2. Entity 라벨 미지정 문제 — 검색 품질 영향 분석

### 현황

| 구분 | 건수 | 비율 |
|------|------|------|
| 전체 Entity 노드 | 129,349 | 100% |
| 라벨 지정 (Concept, Technology, Person 등) | 122,321 | 94.6% |
| **라벨 미지정 (`:Entity`만 보유)** | **7,028** | **5.4%** |

### 검색 품질 영향: **미미함**

**근거**: `search.py`의 `_graph_search()` 메서드 분석 (line 1010~1080)

Graph Search Cypher 쿼리 구조:

```cypher
-- Step 1: Entity 이름 매칭 (line 1016)
MATCH (e:Entity)
WHERE e.name IN $entity_names

-- Step 2: 부분 매칭 (line 1060)
MATCH (e:Entity) WHERE ...
AND any(word IN $query_words WHERE toLower(word) = toLower(e.name))

-- Step 3: 관계 탐색 (line 1075)
OPTIONAL MATCH (e)-[r:RELATED_TO]-(rel:Entity)
```

**핵심 포인트**:
- 모든 쿼리가 `MATCH (e:Entity)`로 시작 — **`:Entity` 라벨만 사용**
- 세부 라벨(`:Concept`, `:Technology`, `:Person` 등)로 필터링하지 않음
- `e.name` 기반 매칭 → `RELATED_TO` 관계 탐색 순서
- 7,028개 미지정 Entity도 `:Entity` 라벨은 보유 → **Graph Search에 정상 포함됨**

### 결론

| 관점 | 영향 | 설명 |
|------|------|------|
| **검색 품질** | 없음 | `:Entity` 라벨로 검색하므로 세부 라벨 유무와 무관 |
| **데이터 정합성** | 있음 | 5.4% Entity의 분류가 미완 → KG 시각화, 통계에 영향 |
| **향후 확장** | 있음 | Entity 타입별 필터 검색(예: "기술만 검색") 구현 시 누락됨 |

### 권고

- **즉시 조치 불필요**: 현재 검색 품질에 영향 없음
- **P1 STORY-088에서 수정**: entity_type 속성 기반 라벨 보정 (데이터 정합성)
- **향후 고려**: Entity 타입별 필터 검색 구현 시 라벨 완전성 필수
