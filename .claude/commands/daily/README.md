# Daily Commands - 일일 마무리 자동화

하루 일과 마무리 작업을 자동화하는 Claude Code 커스텀 명령어 모음입니다.

## 명령어 목록

| 명령어 | 설명 | 용도 |
|--------|------|------|
| `/project:daily:daily-close` | 전체 마무리 | 모든 마무리 작업 일괄 실행 |
| `/project:daily:daily-log` | 작업일지 | 작업일지만 작성/업데이트 |
| `/project:daily:vibe-log` | 바이브 일지 | 바이브 코딩 일지만 작성/업데이트 |
| `/project:daily:sync-docs` | 문서 현행화 | README/CLAUDE/PLAN 업데이트 |

> **참고**: 서브폴더(`daily/`)에 있는 명령어는 `/project:폴더명:명령어` 형식으로 호출합니다.

## 핵심 기능: 업데이트 모드

모든 명령어는 **업데이트 모드**를 지원합니다:

```
기존 파일 있음? → 읽기 → 추가 내용 파악 → 기존 + 신규 병합 → 저장
기존 파일 없음? → 새로 생성
```

**장점**:
- 하루에 여러 번 실행해도 기존 내용 유지
- 추가 작업만 반영하여 업데이트
- 실수로 덮어쓰기 방지

## 사용 시나리오

### 시나리오 1: 퇴근 전 일괄 마무리
```
/project:daily:daily-close
```
→ 커밋 확인 → 작업일지 → 바이브 일지 → 문서 현행화 → 푸시

### 시나리오 2: 작업일지만 작성
```
/project:daily:daily-log
```
→ 작업일지 작성/업데이트만 수행

### 시나리오 3: 추가 작업 후 재마무리
```
# 이미 오늘 마무리 완료 후 추가 작업 발생

/project:daily:daily-close
```
→ 기존 일지에 추가 내용만 반영

### 시나리오 4: 문서만 빠르게 동기화
```
/project:daily:sync-docs
```
→ README.md, CLAUDE.md, PLAN.md만 업데이트

## 생성되는 파일

### 작업일지
```
work_logs/daily_logs/
└── YYYY/
    └── MM-Month/
        └── YYYY-MM-DD.md
```

### 바이브 일지
```
work_logs/vibe_logs/
└── YYYY/
    └── MM-Month/
        └── YYYY-MM-DD-vibe.md
```

### 프로젝트 문서
```
./
├── README.md
├── CLAUDE.md
└── PLAN.md
```

## 커밋 메시지 형식

| 작업 | 커밋 메시지 |
|------|------------|
| 작업일지 | `[DOCS] YYYY-MM-DD 작업일지 작성/업데이트` |
| 바이브 일지 | `[DOCS] YYYY-MM-DD 바이브 코딩 일지 작성/업데이트` |
| 문서 현행화 | `[DOCS] 프로젝트 메인 문서 현행화` |
| 전체 마무리 | `[DOCS] 일일 마무리 - 작업일지, 바이브로그, 문서 현행화` |

## 팁

### 1. 언제 어떤 명령어를 쓸까?

```
퇴근 전 완전 마무리    → /project:daily:daily-close
빠르게 일지만         → /project:daily:daily-log 또는 /project:daily:vibe-log
문서 버전만 올리고 싶을 때 → /project:daily:sync-docs
```

### 2. 업데이트 vs 새 작성

명령어는 자동으로 판단합니다:
- 오늘 날짜 파일 있음 → 업데이트 모드
- 오늘 날짜 파일 없음 → 생성 모드

### 3. 여러 번 실행해도 안전

업데이트 모드 덕분에 같은 명령어를 여러 번 실행해도:
- 기존 내용 유지
- 중복 방지 (같은 내용 재추가 안 함)
- 새 내용만 추가

## 문제 해결

### Q: 기존 내용이 사라졌어요
A: 업데이트 모드가 제대로 동작하지 않은 경우입니다.
   → `git checkout HEAD~1 -- <파일경로>` 로 복구

### Q: 같은 내용이 중복 추가됐어요
A: Claude가 컨텍스트를 잃은 경우입니다.
   → 수동으로 중복 제거 후 재커밋

### Q: 날짜가 잘못 인식됐어요
A: 시스템 시간 확인 후 파일명 수동 변경
