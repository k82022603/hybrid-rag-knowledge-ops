# Antigravity Commands

**개인 실험/학습 용도 전용** - Antigravity Claude Proxy 설정 및 관리 도구

> **중요 고지사항**
>
> 이 스킬들은 **개인 실험/학습 용도**로만 사용하세요.
> - 기업/팀 프로젝트에서는 권장하지 않습니다
> - 서비스 약관(ToS) 위반 가능성이 있습니다
> - 계정 정지/제재 위험을 본인이 감수해야 합니다

---

## 명령어 목록

| 명령어 | 설명 |
|--------|------|
| `/antigravity:setup` | Antigravity Proxy 초기 설정 가이드 |
| `/antigravity:workflow` | UI 개발 워크플로우 (Stitch MCP 연동) |

---

## 사용 방법

### 초기 설정
```
/antigravity:setup
```

### UI 개발 워크플로우
```
/antigravity:workflow 로그인 폼 (이메일, 비밀번호, 반응형)
```
