# Korean API Documentation Skill

한글 API 문서화를 위한 표준과 템플릿을 제공합니다.

## 설치

```bash
# 프로젝트에 이미 포함됨
ls .claude/skills/korean-api-documentation/
```

## 대상 에이전트

- `code-documenter` (Documenter)
- `backend-developer` (Backend) - API 문서화 시

## 주요 내용

1. **엔드포인트 템플릿** - 표준 API 문서 구조
2. **OpenAPI 한글화** - Swagger 문서 작성 규칙
3. **Python Docstring** - Google Style 한글 작성법
4. **에러 코드 문서화** - 표준 에러 문서 형식
5. **용어 표준** - 기술 용어 한글화 가이드
