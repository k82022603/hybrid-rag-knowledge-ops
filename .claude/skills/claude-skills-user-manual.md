## 시작하기

### Claude Skills란?

Claude Skills는 Claude가 특정 작업을 전문적으로 수행할 수 있도록 돕는 확장 기능입니다. 

**주요 특징**:
- 🎯 **자동 실행**: 요청에 맞는 스킬이 자동으로 활성화됩니다
- 🔧 **전문화**: 각 스킬은 특정 작업에 최적화되어 있습니다
- 🔄 **조합 가능**: 여러 스킬을 함께 사용할 수 있습니다
- ✨ **일관성**: 항상 동일한 품질의 결과물을 제공합니다

### 지원 플랫폼

| 플랫폼 | 지원 여부 | 버전 |
|--------|----------|------|
| 🌐 **Claude.ai (웹)** | ✅ 지원 | Pro, Max, Team, Enterprise |
| 💻 **Claude Desktop (Mac)** | ✅ 지원 | Pro, Max, Team, Enterprise |
| 💻 **Claude Desktop (Windows)** | ✅ 지원 | Pro, Max, Team, Enterprise |
| 📱 **Claude Mobile (iOS)** | ✅ 지원 | Pro, Max, Team, Enterprise |
| 📱 **Claude Mobile (Android)** | ✅ 지원 | Pro, Max, Team, Enterprise |

### 필요 조건

- ✅ Claude **Pro, Max, Team, 또는 Enterprise** 플랜
- ✅ 최신 버전의 Claude.ai 또는 Claude Desktop
- ✅ Settings에서 **Skills 기능 활성화**

## Skills 활성화 방법

### Claude.ai (웹) 에서 활성화

#### 1단계: Settings 메뉴 열기

```
1. Claude.ai (https://claude.ai) 접속
2. 왼쪽 사이드바 하단 또는 우측 상단의 프로필 아이콘 클릭
3. "Settings" 또는 "설정" 메뉴 선택
```

#### 2단계: Skills 활성화

```
1. Settings 내에서 "Features" 또는 "Capabilities" 섹션 찾기
2. "Skills" 항목 찾기
3. 토글 버튼을 ON (파란색)으로 전환
4. "Enable Skills" 또는 유사한 확인 버튼 클릭
```

#### 3단계: 확인

```
✅ Skills 토글이 파란색(활성화)으로 표시됨
✅ "Skills enabled" 메시지 표시
✅ 새 대화에서 Skills 사용 가능
```

---

### Claude Desktop (Mac/Windows)에서 활성화

#### 1단계: Settings 메뉴 열기

**Mac**:
```
1. 메뉴바에서 "Claude" → "Settings" 클릭
   또는
2. 단축키: ⌘ + , (Command + Comma)
```

**Windows**:
```
1. 메뉴바에서 "File" → "Settings" 클릭
   또는
2. 단축키: Ctrl + , (Control + Comma)
```

#### 2단계: Skills 활성화

```
1. Settings 창에서 "Features" 탭 선택
2. "Skills" 섹션 찾기
3. "Enable Skills" 체크박스 선택
4. "Save" 또는 "Apply" 버튼 클릭
```

#### 3단계: 앱 재시작 (필요 시)

```
1. Claude Desktop 완전히 종료
2. 다시 실행
3. 새 대화 시작하여 Skills 테스트
```

### Team/Enterprise 사용자

#### 관리자 권한 필요

Team 또는 Enterprise 플랜 사용자는:

1. **조직 관리자**가 먼저 전체 조직에 Skills를 활성화해야 합니다
2. 관리자가 활성화한 후 개별 사용자가 자신의 Settings에서 활성화
3. 관리자에게 문의: "Skills 기능을 활성화해주세요"

#### 관리자 활성화 방법

```
1. Admin Console 접속
2. "Organization Settings" 메뉴
3. "Features" 섹션
4. "Skills" 전체 활성화
5. 모든 팀원에게 공지
```

## 사용 가능한 Skills 목록

### 📄 문서 작성 Skills

#### 1. pptx (PowerPoint)
```
기능: 프레젠테이션 제작
- PPT 파일 생성 (.pptx)
- 슬라이드 편집 및 수정

- 발표자 노트 추가
- 템플릿 사용

사용 예시:
"AI 트렌드 프레젠테이션 5장 만들어줘"
"분기 실적 보고 PPT 만들어줘 (차트 포함)"

#### 2. docx (Word)
```
기능: 워드 문서 작성

- 표, 이미지 삽입
- 변경 사항 추적
- 코멘트 추가

사용 예시:
"프로젝트 제안서를 Word로 작성해줘"
"회의록을 docx 파일로 만들어줘"

기능: 스프레드시트 작성

- 조건부 서식

사용 예시:
"월별 매출 데이터를 엑셀로 정리해줘"
"예산 계획 스프레드시트 만들어줘"
```

#### 4. pdf (PDF)
```
기능: PDF 문서 처리
- PDF 생성
- 양식 작성
- 텍스트 추출
- PDF 병합/분할

사용 예시:
"이 문서를 PDF로 만들어줘"

## 기본 사용법

### 자동 스킬 호출

Skills는 **자동으로 실행**됩니다. 별도로 선택할 필요가 없습니다!

#### 예시 1: 문서 작성
```
사용자: "AI 트렌드에 대한 프레젠테이션 5장 만들어줘"

Claude: [자동으로 pptx 스킬 실행]
         프레젠테이션을 만들겠습니다...
         [PPT 파일 생성]
```

#### 예시 2: 테마 적용
```
사용자: "Ocean Depths 테마로 프레젠테이션 만들어줘"

Claude: [pptx + theme-factory 스킬 자동 실행]
         Ocean Depths 테마를 적용하여 프레젠테이션을 만듭니다...
         [테마가 적용된 PPT 생성]
```

#### 예시 3: 데이터 분석
```
사용자: "이 데이터를 엑셀로 분석해줘"

Claude: [xlsx 스킬 자동 실행]
         데이터를 분석하고 엑셀 파일로 정리하겠습니다...
         [Excel 파일 생성]
```

---

### 명시적 스킬 호출

원하는 스킬을 **명시적으로 지정**할 수도 있습니다:

```
"pptx 스킬을 사용해서 프레젠테이션 만들어줘"
"theme-factory로 Modern Minimalist 테마 적용해줘"
"docx 스킬로 보고서 작성해줘"
```

---

### 여러 스킬 조합

여러 스킬을 **동시에 사용**할 수 있습니다:

```
"Ocean Depths 테마를 적용한 분기 실적 보고 PPT를 만들어줘"
→ pptx + theme-factory 스킬 조합

"회사 브랜드 가이드에 맞춰 프레젠테이션 만들어줘"
→ pptx + brand-guidelines 스킬 조합

"데이터 분석해서 엑셀로 정리하고, 요약 PPT도 만들어줘"
→ xlsx + pptx 스킬 조합
```

"분기 실적 리포트를:
1. 경영진용 PPT (요약, 차트 중심)
2. 상세 Word 문서 (분석 내용 전체)
3. 배포용 PDF (읽기 전용)"
```

## 문제 해결

### 문제 1: Skills가 작동하지 않음

#### 증상
```
- Skills 메뉴가 보이지 않음
- 요청해도 스킬이 실행되지 않음
- 에러 메시지 표시
```

#### 해결 방법

**1단계: 플랜 확인**
```
✅ Pro, Max, Team, Enterprise 플랜인지 확인
❌ Free 플랜은 Skills 미지원
```

**2단계: Skills 활성화 확인**
```
Settings → Features → Skills 토글 확인
파란색(ON) 상태여야 함
```

**3단계: 앱 버전 확인**
```
최신 버전으로 업데이트
Claude Desktop: Help → Check for Updates
```

**4단계: 재시작**
```
웹: 브라우저 새로고침 (Ctrl+F5 또는 Cmd+Shift+R)
Desktop: 앱 완전 종료 후 재시작
```

**5단계: 캐시 삭제**
```
브라우저 캐시 삭제
Claude Desktop 설정에서 캐시 삭제
```

---

### 문제 2: 특정 스킬만 작동 안 함

#### 증상
```
다른 스킬은 되는데 특정 스킬만 안 됨
```

#### 해결 방법

**1단계: 명시적 요청**
```
"pptx 스킬을 사용해서 프레젠테이션 만들어줘"
```

**2단계: 더 구체적인 요청**
```
❌ "문서 만들어줘"
✅ "PowerPoint 프레젠테이션 5장 만들어줘"
```

**3단계: 요구사항 확인**
```
일부 스킬은 특정 입력 필요
예: theme-factory는 문서/프레젠테이션 함께 요청
```

---

### 문제 3: Team/Enterprise 사용자

#### 증상
```
Settings에 Skills 메뉴가 없음
```

#### 해결 방법

**관리자에게 요청**
```
조직 관리자가 먼저 전체 조직에 
Skills를 활성화해야 함

관리자에게 문의:
"Skills 기능을 조직에 활성화해주세요"
```

---

### 문제 4: 파일 다운로드 안 됨

#### 증상
```
파일이 생성되었다고 하는데 다운로드 링크가 없음
```

#### 해결 방법

**1단계: 링크 확인**
```
Claude의 응답에서 
[View your file](computer://...) 링크 찾기
```

**2단계: 다시 요청**
```
"방금 만든 파일 다운로드 링크 다시 줘"
```

**3단계: 다른 형식으로**
```
"이 내용을 artifact로 보여줘"
(화면에서 직접 확인 가능)
```

---

### 문제 5: 결과가 기대와 다름

#### 증상
```
요청한 것과 다른 결과물
```

#### 해결 방법

**더 구체적으로 요청**
```
❌ "프레젠테이션 만들어줘"

✅ "AI 트렌드 프레젠테이션을 만들어줘:
   - 5개 슬라이드
   - Ocean Depths 테마
   - 차트 2개 포함
   - 16:9 비율
   - 발표자 노트 포함"
```

**단계별 진행**
```
1. 먼저 구조 확인
2. 테마 선택
3. 내용 작성
4. 검토 및 수정
```

## FAQ

### Q1: Skills는 무료인가요?

**A:** Skills는 **Pro, Max, Team, Enterprise** 플랜에서만 사용 가능합니다. Free 플랜에서는 사용할 수 없습니다.

| 플랜 | Skills 사용 |
|------|------------|
| Free | ❌ 불가 |
| Pro | ✅ 가능 |
| Max | ✅ 가능 |
| Team | ✅ 가능 |
| Enterprise | ✅ 가능 |

---

### Q2: 어떤 스킬을 사용해야 할지 모르겠어요

**A:** 스킬을 **자동으로 선택**해주므로 걱정하지 않아도 됩니다!

```
그냥 원하는 작업을 요청하면:
"프레젠테이션 만들어줘" → pptx 스킬 자동 실행
"엑셀로 정리해줘" → xlsx 스킬 자동 실행
"Ocean Depths 테마로" → theme-factory 자동 실행
```

원하는 스킬을 명시할 수도 있습니다:
```
"pptx 스킬을 사용해서..."
"theme-factory로..."
```

---

### Q3: 한 번에 여러 스킬을 사용할 수 있나요?

**A:** 네, 가능합니다! 여러 스킬이 **자동으로 조합**됩니다.

```
예시:
"Ocean Depths 테마를 적용한 분기 실적 PPT를 만들어줘"
→ pptx + theme-factory 스킬 자동 조합

"데이터 분석해서 엑셀로 정리하고, 요약 PPT도 만들어줘"
→ xlsx + pptx 스킬 자동 조합
```

---

### Q4: 생성된 파일은 어떻게 다운로드하나요?

**A:** Claude가 제공하는 **다운로드 링크**를 클릭하면 됩니다.

```
Claude의 응답:
"프레젠테이션을 만들었습니다.
[View your presentation](computer://...)"

→ 링크 클릭하여 다운로드
```

링크가 안 보이면:
```
"방금 만든 파일 다운로드 링크 다시 줘"
```

---

### Q5: 모바일에서도 사용할 수 있나요?

**A:** 네, iOS와 Android 앱 모두에서 사용 가능합니다!

```
iOS: App Store에서 Claude 앱 설치
Android: Play Store에서 Claude 앱 설치

Settings에서 Skills 활성화
데스크톱과 동일하게 사용
```

---

### Q6: 어떤 파일 형식을 지원하나요?

**A:** 다양한 문서 형식을 지원합니다:

| 형식 | 지원 | 스킬 |
|------|------|------|
| .pptx | ✅ | pptx |
| .docx | ✅ | docx |
| .xlsx | ✅ | xlsx |
| .pdf | ✅ | pdf |
| .html | ✅ | artifacts-builder |
| .png | ✅ | canvas-design |
| .gif | ✅ | slack-gif-creator |
| .jsx | ✅ | artifacts-builder |

PowerPoint, Word, Excel 등에서 직접 편집
```
