**Hybrid RAG Knowledge Ops**는 Graph RAG 기반 지능형 지식 검색 시스템입니다:

## Hybrid Retrieval

```python
class HybridRetriever:
    async def retrieve(self, query: str, top_k: int = 5):
        # 1. Parallel retrieval
        es_results, neo_results = await asyncio.gather(
            self.es.search(query, top_k=20),
            self.neo4j.graph_search(query, top_k=20)
        )
        
        # 2. RRF Fusion
        fused = self._rrf_fusion(es_results, neo_results)
        
        # 3. Reranking
        reranked = await self.rerank(query, fused)
        
        return reranked[:top_k]
    
    def _rrf_fusion(self, es_results, neo_results):
        scores = defaultdict(float)
        k = 60  # RRF constant
        
        for rank, doc in enumerate(es_results):
            scores[doc.id] += 1 / (k + rank + 1)
        for rank, doc in enumerate(neo_results):
            scores[doc.id] += 1 / (k + rank + 1)
        
        return sorted(
            set(es_results + neo_results),
            key=lambda d: scores[d.id],
            reverse=True
        )
```

## Gleaning Implementation

```python
async def gleaning_extraction(text: str, max_rounds: int = 3):
    """
    참고: 33% 품질 향상
    """
    extracted = {}
    
    for round in range(max_rounds):
        if round == 0:
            prompt = f"Extract entities from: {text}"
        else:
            prompt = f"Find ADDITIONAL entities missed. Previous: {extracted}"
        
        new_entities = await llm.ainvoke(prompt)
        merge(extracted, new_entities)
        
        if not new_entities:
            break
    
    return deduplicate(extracted)
```

poetry run mypy src/ || exit 1

    echo "❌ Coverage too low: $COVERAGE%"
    exit 1

poetry run python benchmarks/ragas/evaluate.py
FAITHFULNESS=$(jq -r '.scores.faithfulness' benchmarks/ragas/results/latest.json)
if (( $(echo "$FAITHFULNESS < 0.9" | bc -l) )); then
    echo "❌ Faithfulness too low: $FAITHFULNESS"
    exit 1
fi

echo "✅ All quality gates passed!"
