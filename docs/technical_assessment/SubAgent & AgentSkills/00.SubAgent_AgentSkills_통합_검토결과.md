### 📄 03. Web Design System Agent Skill 완전 가이드

**개요**: Verbalized Sampling 기법 및 한글 웹 디자인 가이드

**핵심 내용**:

1. **Verbalized Sampling 4단계**:
   ```
   1. 클리셰 식별 → 2. 제약 적용 → 3. 발산적 탐색 → 4. 품질 가드레일
   ```

2. **Anti-Pattern Libraries**:
   - 색상: Bootstrap Blue (#007bff) 피하기
   - 레이아웃: 중앙 정렬 Hero, 3-Column Grid 피하기
   - 타이포: Arial/Helvetica 단독 사용 피하기

3. **한글 타이포그래피 최적화**:
   ```css
   font-family: 'Pretendard Variable', sans-serif;
   line-height: 1.6 ~ 1.8;
   word-break: keep-all;
   letter-spacing: -0.02em;
   ```

4. **WCAG 2.1 AA 접근성**:
   - 색상 대비 4.5:1 이상
   - 터치 타겟 44x44px 이상

**프로젝트 적용**:
- web-designer 에이전트가 이 기법 활용
- `.claude/skills/web-design-system/` 스킬 존재

**상태**: ✅ 검토 완료 (최고 품질 문서)

### 📄 05. "절대 흘려듣지 마세요": AI 시대 아키텍처 원칙

**개요**: AI 코드 생성 시대의 아키텍처 안티패턴 경고

**핵심 메시지**:
> "AI는 당신의 아키텍처를 깨뜨리지 않는다. 조용히 구부려서 형태를 잃게 만든다."

**2가지 핵심 안티패턴**:

| 안티패턴 | 문제점 | 올바른 방식 |
|----------|--------|------------|
| **Controller → Repository 직접 호출** | 계층 분리 붕괴, 비즈니스 로직 분산 | Controller → Service → Repository |
| **Service에 RequestDTO 전달** | 도메인 독립성 깨짐, 재사용 불가 | DTO → Domain 변환 후 Service 호출 |

**AI Architectural Drift 징후**:
- 일관성 없는 패턴
- 강하게 결합된 컴포넌트
- 중복/복제된 로직
- 기본값에 대한 과도한 의존

**실천적 조언 6가지**:
1. Skills로 아키텍처 인코딩
2. Architecture-First 워크플로우
3. 자동화된 아키텍처 검증 (ArchUnit)
4. Code Review에서 아키텍처 최우선
5. 교육과 문서화 투자
6. AI를 아키텍처 검증에 활용

**프로젝트 적용**:
- ✅ Backend Developer 에이전트에 안티패턴 경고 추가
- ✅ `layered-architecture-enforcer` 스킬 생성

**상태**: ✅ 검토 완료 + 프로젝트 적용 완료
