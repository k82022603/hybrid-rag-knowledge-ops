## Inspiration & Insights

### 1. FlagEmbedding vs sentence-transformers: 같은 모델, 다른 인터페이스

오늘 가장 흥미로운 발견. 같은 `BAAI/bge-m3` 모델을 두 라이브러리로 로드하면:
- **Dense 벡터**: 완전히 동일 (코사인 유사도 0.7867 일치)
- **Sparse 벡터**: FlagEmbedding만 지원 (`lexical_weights`)
- **ColBERT 벡터**: FlagEmbedding만 지원

결론: 모델 가중치가 같으니 Dense 품질은 동일하지만, Hybrid RAG의 핵심인 Sparse+Dense 조합을 쓰려면 FlagEmbedding이 필수. sentence-transformers는 안정적인 폴백 역할.

### 2. transformers 5.0.0 Breaking Change의 교훈

**import 체인 추적 과정이 인상적**:
```
FlagEmbedding/__init__.py → inference/__init__.py → auto_reranker.py
→ reranker/decoder_only/layerwise.py → models/modeling_minicpm_reranker.py (line 53)
```

5단계 import chain을 타고 가서야 실제 실패 지점 발견. Python 생태계에서 transitiv dependency 문제가 얼마나 깊을 수 있는지 체감.

### 4. 2-tier Fallback 패턴

```python
try:
    from FlagEmbedding import BGEM3FlagModel  # Primary
    model = BGEM3FlagModel(...)
except ImportError:
    from sentence_transformers import SentenceTransformer  # Fallback
    model = SentenceTransformer(...)
```

이 패턴이 오늘 실제로 동작하는 것을 확인. Primary가 실패해도 Fallback이 Dense 벡터를 정상 생성. 프로덕션에서 이런 graceful degradation이 핵심.
