- **Claude Code (클로드)**: 사용자와의 직접 대화

### 문서화의 가치

오늘 MCP 문서 5개를 현행화하면서 느낀 점: 문서는 "작성"보다 "유지"가 어렵다.

```
초기 작성 → 코드 변경 → 문서 미반영 → 문서 신뢰도 하락 → 아무도 안 봄
```

이 악순환을 끊으려면 변경 시점에 문서도 함께 업데이트해야 한다. 오늘처럼.
