### 1. Jira-free 백로그 관리의 발견

> "Jira 계정 없이도 백로그 관리가 가능하다"

**인사이트**:
- Markdown 기반 백로그는 버전 관리와 동기화에 더 유리
- Given-When-Then 형식은 도구에 독립적
- 추후 Jira 연동 시 자동 동기화 가능

**적용**:
```

├── stories/STORY-001-xxx.md  # Story 정의
└── sprints/sprint-01.md      # Sprint 계획
```

### 3. 텍스트 도식 vs Mermaid

> "Mermaid는 유지보수성과 렌더링 품질 모두 향상시킨다"

**비교**:
| 항목 | 텍스트 도식 | Mermaid |
|------|------------|---------|
| 에디터 호환 | ✅ 모든 에디터 | ✅ 대부분 에디터 |
| GitHub 렌더링 | ❌ 깨짐 | ✅ 완벽 |
| 수정 용이성 | ❌ 복잡 | ✅ 코드처럼 수정 |
| 자동 정렬 | ❌ 수동 | ✅ 자동 |

**결론**: 문서의 도식은 Mermaid로 표준화
