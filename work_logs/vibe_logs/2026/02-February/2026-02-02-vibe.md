## Inspiration & Insights

### 1. 병렬 에이전트 실행의 효율성
오늘 QA와 Infra 에이전트를 동시에 실행하면서 병렬 처리의 효율성을 체감했다.

```
사용자 요청 → 클로드 분석 → QA + Infra 동시 실행 → 각자 Slack 알림 → 결과 통합
```

**Key Insight**: 독립적인 작업은 병렬로, 의존적인 작업은 순차적으로. 이 원칙이 에이전트 협업에서도 그대로 적용된다.

### 2. 의존성 문제 해결 패턴
kp-ai-service 문제 해결 과정에서 발견한 패턴:

```
컨테이너 장애 → 로그 확인 → 누락 패키지 식별 → Dockerfile 수정 → 재빌드
```

- `email-validator`: pydantic의 EmailStr은 기본 포함이 아님
- `python-multipart`: FastAPI form data는 명시적 설치 필요
- Poetry 2.x: `poetry-plugin-export` 분리됨

**교훈**: "암묵적 의존성"은 컨테이너 환경에서 명시적으로 드러난다.

### 3. E2E 테스트와 환경 의존성
49.5% 통과율이 낮아 보이지만, 실제로는:
- UI/접근성 테스트: 대부분 통과
- API 통합 테스트: Backend 서버 필요

**Insight**: E2E 테스트는 "환경 테스트"이기도 하다. 테스트 실패는 때때로 환경 문제를 먼저 알려준다.
