### 2. Docker Desktop 데이터 이동의 함정
C: 드라이브 공간 문제로 Docker 데이터를 D: 드라이브로 이동하려 했다.

**시도한 방법들**:
1. Junction 링크 → settings.json의 dataFolder와 충돌
2. settings.json만 변경 → 기존 vhdx와 호환 문제
3. 기존 vhdx 복구 → Docker Engine 시작 실패

**배운 점**:
- Docker Desktop의 WSL 2 백엔드는 생각보다 까다로움
- vhdx 파일은 버전 호환성 이슈가 있을 수 있음
- 때로는 Factory Reset이 가장 빠른 해결책
- docker-compose.yml이 있으면 언제든 재빌드 가능 → 데이터 손실 두려움 감소
