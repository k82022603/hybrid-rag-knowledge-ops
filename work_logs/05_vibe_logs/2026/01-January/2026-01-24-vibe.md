## Technical Discoveries

### 1. Docker Compose Override 패턴
```yaml
# docker-compose.yml (프로덕션 보안)
user: "7474:7474"
cap_drop: [ALL]

# docker-compose.wsl2.yml (개발 편의)
user: ""
cap_drop: []
```

Override 파일로 환경별 설정을 깔끔하게 분리.
베이스는 엄격하게, 오버라이드는 유연하게.

### 2. Healthcheck 호환성
```bash
# 실패 (BusyBox Alpine)
wget --spider http://localhost:80/

# 성공
wget -q -O /dev/null http://127.0.0.1:80/
```

컨테이너 내부에서 직접 테스트해야 알 수 있는 것들.

### 3. GitHub Actions 검증
CI에서 docker compose 설정을 검증하는 워크플로우 추가.
"검증 가능한 것은 검증하라"는 원칙 실천.
