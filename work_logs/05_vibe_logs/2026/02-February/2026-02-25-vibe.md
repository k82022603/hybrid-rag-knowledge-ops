## Inspiration & Insights

### "빌드 캐시 지우면 모델 날아가는 거 아니야?"
- 사용자의 이 질문이 Docker 레이어 구조를 설명하는 좋은 기회가 됨
- Build Cache vs Image Layer vs Volume — 세 가지는 완전히 분리된 저장소
- BGE-M3 모델(~2.5GB)은 Dockerfile `COPY` 시점에 이미지 레이어에 굳어짐
- 빌드 캐시를 지워도 이미 빌드된 이미지는 영향 없음
- **교훈**: Docker 사용자 대부분이 이 구분을 모름 → 매뉴얼에 반드시 설명해야 하는 부분

### vhdx가 안 줄어드는 진짜 이유
- Docker에서 데이터 삭제해도 디스크 사용량이 안 줄어서 당황하는 사람 많음
- WSL2의 ext4.vhdx/docker_data.vhdx는 "최고 수위 표시"처럼 동작
- 안의 데이터가 줄어도 바깥(NTFS) 파일 크기는 유지됨
- `Optimize-VHD` 또는 `diskpart compact`로 수동 축소 필요
- **아이러니**: WSL 종료해야 축소 가능 → Claude Code 세션도 날아감
