| pytest 실행 | HANG | langgraph 설치 미완 상태에서 실행 시도 |
| 에이전트 강제 중단 | KILL | 260초+ 무출력으로 TaskStop 실행 |

#### 근본 원인 분석

```
pytest 실행 체인:
  pytest → conftest.py → from app.main import app
  → app.api.routes (전체 라우터 import)
  → langgraph/langchain 의존성 → 미설치로 import 실패 → hang
```

**문제**: conftest.py가 `from app.main import app`을 import하며, app 초기화 시 전체 라우터가 로드됨.
일부 라우터가 langgraph/langchain에 의존하는데, 에이전트가 이 패키지를 설치하는 중에 중단됨.

#### 해결 방법 (수동 실행)

```bash
# 현재 상태: langgraph/langchain 이미 설치됨 (에이전트가 일부 완료)
cd knowledge_service
PYTHONPATH=src .venv/bin/python -m pytest src/tests/unit/test_document_upload.py -v --tb=short
```

**결과**: 25 passed, 29 warnings in 1.31s

#### 향후 재발 방지 대책

| 대책 | 설명 | 우선순위 |
|------|------|:--------:|
| `PYTHONPATH=src` 표준화 | pyproject.toml에 `[tool.pytest.ini_options] pythonpath = ["src"]` 추가 | P0 |
| 테스트 격리 | unit 테스트 conftest.py를 별도로 두어 전체 app import 회피 | P1 |
| `--noconftest` 가이드 | 독립 테스트 실행 시 `--noconftest` 사용 문서화 | P2 |
| pytest-timeout 설치 | `pip install pytest-timeout` 후 기본 타임아웃 설정 | P2 |
