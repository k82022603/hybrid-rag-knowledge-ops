## 주제 토론: "우리의 사용자"

### 핵심 인사이트

#### 1. 사용자 프로필
- **주 사용자**: 기업 내 지식 검색이 필요한 임직원
- **대상**: 기술 문서, 정책, 가이드를 찾는 개발자/관리자
- **특징**: 기업 내부 시스템이라 사용자 선택권이 없음 -> 우리가 먼저 품질을 보장해야 함

#### 2. Hybrid RAG의 사용자 가치

| 검색 방식 | 사용자 가치 | 예시 |
|----------|-----------|------|
| **Keyword (ES)** | 정확한 용어 매칭 | "연차 정책" 검색 |
| **Vector (임베딩)** | 의미적 유사성 | "휴가 쓰는 방법" -> 연차 정책 연결 |
| **Graph (Neo4j)** | 관계적 맥락 | "CI/CD" 검색 -> 관련 배포 정책, 도구, 팀 연결 |
| **Hybrid (삼중)** | 빈 결과 최소화 + 의도 이해 | 단일 방식 실패 시 다른 방식으로 보완 |

#### 3. 오늘 수정한 버그와 사용자 영향

| 버그 | 사용자 영향 | 심각도 |
|------|-----------|--------|
| Gateway 405 | 검색 자체 불가 | Critical |
| 그래프 빈 결과 | 그래프 탭 무용지물 | High |
| Lucene 500 | CI/CD 등 기술용어 검색 불가 | High |
| JWT 401 | 로그인 후에도 접근 불가 | Critical |
| 503 Timeout | 시스템 장애로 인식 | Critical |
| Graph 배지 UX | 잘못된 정보 표시 -> 신뢰 하락 | Medium |

#### 4. 팀 공통 인식
- "모든 버그는 곧 사용자 이탈이다"
- "Hybrid RAG의 핵심 가치는 빈 결과를 최소화하고 사용자 의도를 이해하는 것"
- "기업 내부 시스템이라 사용자에게 선택권이 없기 때문에 우리가 먼저 품질을 보장해야 한다"
- "보이지 않는 인프라/데이터 품질이 사용자 경험의 기반"
