# 📝 Work Logs & Vibe Logs

프로젝트 작업 기록 및 개발 일지 관리 폴더입니다.

## 📁 폴더 구조

```
work_logs/
├── daily_logs/          # 📋 일일 작업 일지
│   ├── 2026/
│   │   └── 01-January/
│   │       ├── 2026-01-12.md
│   │       ├── 2026-01-13.md
│   │       ├── 2026-01-14.md
│   │       └── 2026-01-15.md
│   └── README.md        # 작업 일지 가이드
│
├── vibe_logs/           # 💡 바이브 코딩 일지 (영감/아이디어)
│   ├── 2026/
│   │   └── 01-January/
│   │       ├── 2026-01-14-vibe.md
│   │       └── 2026-01-15-vibe.md
│   └── README.md        # 바이브 로그 가이드
│
└── README.md            # 이 파일
```

## 🎯 구분

### 📋 Daily Logs (작업 일지)
**목적**: 무엇을 했는가를 기록

- 완료된 작업 목록
- 의사결정 및 근거
- 발견된 문제와 해결 방법
- 다음 단계 계획
- 시간 추적

📖 가이드: [daily_logs/README.md](./daily_logs/README.md)

### 💡 Vibe Logs (바이브 로그)
**목적**: 왜 그렇게 했는가를 이해

- 깨달음과 인사이트
- 사고 과정
- 설계 철학
- 미래 아이디어
- 개인적 관점

📖 가이드: [vibe_logs/README.md](./vibe_logs/README.md)

## 🚀 빠른 시작

### 작업 일지 생성

```bash
# PowerShell (Windows)
.\scripts\create_worklog.ps1

# Bash (Linux/Mac)
./scripts/create_worklog.sh
```

### 바이브 로그 작성

매일 저녁 또는 원할 때 언제든지:
```
vibe_logs/2026/01-January/YYYY-MM-DD-vibe.md 파일 생성
```
