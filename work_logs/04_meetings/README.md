```
meetings/
```

## 파일명 규칙

- **형식**: `YYYY-MM-DD_<meeting_type>.md`
- **예시**:
  - `2026-01-28_sprint03_completion_review.md` (스프린트 완료 리뷰)
  - `2026-02-01_sprint04_kickoff.md` (스프린트 킥오프)
  - `2026-02-15_architecture_review.md` (아키텍처 리뷰)

## 회의 유형

| 유형 | 설명 | 주기 |
|------|------|------|
| `sprint_completion_review` | 스프린트 완료 검토 | 스프린트 종료 시 |
| `sprint_kickoff` | 스프린트 킥오프 | 스프린트 시작 시 |
| `architecture_review` | 아키텍처 리뷰 | 필요 시 |
| `retrospective` | 회고 | 스프린트 종료 시 |
| `tech_review` | 기술 검토 | 필요 시 |
