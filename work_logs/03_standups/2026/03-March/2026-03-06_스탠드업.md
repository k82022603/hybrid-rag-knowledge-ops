### 핵심 신기능
1. **네이티브 Computer Use** — Playwright 코드 + 스크린샷 기반 마우스/키보드 제어
2. **Tool Search** — 도구 정의를 온디맨드 검색 (전체 로딩 불필요, 47% 토큰 절감)
3. **ChatGPT for Excel/Sheets** — 스프레드시트 내장 AI (베타)

### 논의 결과

#### 1. 런타임 LLM (DeepSeek V3.2) 전략 -> 현행 유지

| 비교 | DeepSeek V3.2 | GPT-5.4 |
|------|--------------|---------|
| Input 가격 | ~$0.14/1M | $2.50/1M |
| Output 가격 | ~$0.28/1M | $15.00/1M |
| 격차 | - | 입력 18x, 출력 54x |

- RAG는 Faithfulness(충실도) 기반 — 검색 품질 > LLM 성능
- DeepSeek로 이미 Faithfulness 0.85+ 달성 중
- 고난도 분석 기능(정책 비교 등)에 한정하여 GPT-5.4 Pro 선택적 검토 가능

#### 2. Tool Search 개념 -> Sprint 11~12 파일럿

- 현재 `classify_query_type` 정적 분류 -> 의미 기반 동적 선택 메타 레이어로 진화
- 적용 영역: ES 벡터검색 / BM25 / Neo4j 그래프 탐색 중 동적 선택
- RAG 파이프라인 레벨에서 우선 적용, 효과 측정 후 확대

#### 3. Computer Use E2E 테스트 -> 중장기 Sprint 12~13 검토

- 현 시점 Playwright 스크립트가 재현 가능성/CI/CD 통합성 우위
- AI-assisted 탐색적 테스트, 시각적 회귀 테스트, 접근성 테스트 보조 가능성
- Claude Computer Use vs GPT-5.4 Computer Use 비교 평가 필요
