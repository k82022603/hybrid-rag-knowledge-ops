# Session Logs

Claude Code 세션 기록을 관리하는 폴더입니다.

## 폴더 구조

```
session_logs/
├── README.md                          # 이 파일
└── YYYY-MM-DD_description.md          # 세션 로그 파일
```

## 파일 명명 규칙

**형식**: `YYYY-MM-DD_description.md`

- **YYYY-MM-DD**: 날짜 (예: 2026-01-21)
- **description**: 세션 주요 작업 요약 (영문 소문자, 언더스코어 구분)

**예시**:
- `2026-01-21_kibana_standup.md` - Kibana 문서화 및 스탠드업 세션
- `2026-01-21_e2e_test.md` - E2E 테스트 세션
- `2026-01-22_sprint02_planning.md` - Sprint 02 계획 세션

> **참고**: 하루에 여러 세션이 있는 경우 description으로 구분

## 세션 로그 내용

각 세션 로그에는 다음 내용이 포함됩니다:

1. **세션 요약**: 주요 작업 한줄 요약
2. **완료된 작업**: 상세 작업 목록 및 변경 내용
3. **주요 결정사항**: 세션 중 결정된 기술/설계 사항
4. **변경된 파일 목록**: 수정/생성된 파일 목록
5. **현재 프로젝트 상태**: 인프라, Sprint 상태
6. **다음 작업**: P0/P1/P2 우선순위별 액션 아이템
7. **리스크 모니터링**: 확률, 영향, 대응 계획
8. **사용된 도구 및 에이전트**: 세션 중 활용한 도구
9. **세션 통계**: 수정 파일 수, 메시지 수 등

## 사용 방법

### Claude Code 명령어

```bash
/daily:session-log           # 세션 로그 작성/업데이트
/daily:session-log start     # 새 세션 시작
/daily:session-log end       # 세션 종료
/daily:session-log update    # 업데이트 모드
```

## 용도

- **작업 연속성**: 이전 세션에서 수행한 작업 추적
- **컨텍스트 복원**: 새 세션 시작 시 참조
- **프로젝트 히스토리**: 시간 순서별 작업 기록
- **에이전트 협업**: 에이전트 간 작업 인수인계

## 관련 폴더

| 폴더 | 용도 |
|------|------|
| `daily_logs/` | 일일 작업 일지 (무엇을 했는가) |
| `vibe_logs/` | 바이브 코딩 일지 (왜 그렇게 했는가) |
| `standups/` | 스탠드업 미팅 기록 (팀 상태 공유) |
| `session_logs/` | 세션 로그 (Claude Code 세션 기록) |
