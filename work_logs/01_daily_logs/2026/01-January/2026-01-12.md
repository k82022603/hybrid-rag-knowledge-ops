## 📚 Learnings

### Elasticsearch 라이선스 정책
- RRF (Reciprocal Rank Fusion)는 Platinum 이상에서만 사용 가능
- `sparse_vector` 필드 타입은 Basic에서도 사용 가능
- 외부 모델로 생성한 벡터 저장은 무료

### BGE-M3 임베딩
- Dense + Sparse 벡터를 동시에 생성 가능
- FlagEmbedding 라이브러리 직접 사용 필요 (LangChain HuggingFaceEmbeddings는 Dense만)
- Sparse Vector는 명시적 키워드 매칭으로 정확도 5-10% 향상

### LlamaIndex vs LangGraph
- 단순 메타데이터 기반 라우팅 → LlamaIndex RouterQueryEngine
- 복잡한 다단계 워크플로우 → LangGraph
