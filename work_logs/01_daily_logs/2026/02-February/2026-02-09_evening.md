#### ES Scroll Timeout 근본 해결

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| scroll_timeout | `10m` (하드코딩) | `60m` (기본, CLI 조정 가능) |
| scroll_size | `100` (기본) | `20` (기본) |
| CLI 인자 | `--scroll-size`만 | `--scroll-timeout` 추가 |

**핵심 공식**:
```
페이지 처리 시간 = (scroll_size / batch_size) x 배치 소요시간

변경 전: (100/4) x 420초 = 10,500초 >> 600초(10분) → 실패
변경 후: (20/4) x 420초  = 2,100초  << 3,600초(60분) → 성공
```
