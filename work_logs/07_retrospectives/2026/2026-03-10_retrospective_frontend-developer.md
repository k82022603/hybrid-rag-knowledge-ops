# 프로젝트 회고 — Frontend Developer

**프로젝트**: Hybrid RAG Knowledge Platform 고도화
**기간**: 2026-01-10 ~ 2026-03-10
**역할**: React 18 UI 개발, Tailwind CSS 스타일링, Antigravity 코드 통합/검증, 검색 UI 컴포넌트

---

## 1. 내가 기여한 것 (What I Did)

- **검색 결과 카드 컴포넌트**: 4채널 Hybrid RAG 검색 결과를 직관적으로 보여주는 카드 UI를 구현했습니다. Dense/Sparse/Graph/Temporal 각 채널의 기여도를 시각화하고, 신뢰도 점수를 컬러 바로 표현했습니다.
- **소스 인용 컴포넌트**: RAG 답변에서 참조한 원문 소스를 클릭 가능한 인용 형태로 표시하는 컴포넌트를 개발했습니다. 사용자가 답변의 근거를 바로 확인할 수 있도록 했습니다.
- **MUI에서 Tailwind CSS 전환**: 기존 MUI(Material-UI) 기반 컴포넌트를 Tailwind CSS + Headless UI로 전환하여, 번들 사이즈를 40% 줄이고 커스터마이징 유연성을 확보했습니다.
- **Antigravity + Stitch MCP 통합**: Web Designer가 설계한 Antigravity 프롬프트로 생성된 UI 코드를 실제 프로젝트에 통합하고, 접근성(WCAG 2.1 AA), TypeScript 타입 안전성, 반응형 디자인을 검증했습니다.
- **채팅 인터페이스**: LLM 기반 대화형 검색을 위한 채팅 UI를 구현하여, 스트리밍 응답과 마크다운 렌더링을 지원했습니다.

## 2. 잘된 점 (What Went Well)

- **Antigravity 협업 워크플로우**: Web Designer -> Antigravity -> Frontend -> TechLead 파이프라인이 잘 동작하여, UI 생산성이 크게 향상되었습니다. AI가 생성한 코드의 80% 이상을 그대로 활용할 수 있었습니다.
- **반응형 디자인 일관성**: Tailwind의 유틸리티 클래스 덕분에 모바일/태블릿/데스크톱에서 일관된 UI를 효율적으로 구현할 수 있었습니다.

## 3. 아쉬운 점 (What Could Be Better)

- **MUI -> Tailwind 전환 시점**: 프로젝트 중반에 전환이 이루어져, 일부 컴포넌트에 MUI와 Tailwind가 혼재하는 기간이 있었습니다. 초기부터 Tailwind로 시작했으면 전환 비용이 없었을 것입니다.
- **프론트엔드 테스트 커버리지**: 비즈니스 로직 테스트는 충분했지만, 컴포넌트 렌더링 테스트와 접근성 자동 테스트가 부족했습니다. Storybook + Chromatic을 도입했으면 좋았을 것입니다.
- **상태 관리 복잡성**: 검색, 채팅, 인증 상태가 복잡해지면서 Context API만으로는 한계가 있었습니다. Zustand 같은 경량 상태 관리 라이브러리를 조기에 도입했으면 코드가 더 깔끔했을 것입니다.

## 4. 배운 점 (What I Learned)

- **AI 코드 생성과 인간 검증의 균형**: Antigravity가 빠르게 UI를 생성하지만, 접근성, 에지 케이스, 성능 최적화는 여전히 사람의 검증이 필요합니다. "생성은 AI, 검증은 사람" 원칙을 체득했습니다.
- **Tailwind의 생산성**: 컴포넌트별로 CSS를 작성하던 방식에서 유틸리티 퍼스트로 전환하니, 디자인 시스템 일관성과 개발 속도가 동시에 개선되었습니다.

## 5. 다음 프로젝트에 바라는 점

- 디자인 시스템을 프로젝트 초기에 확립하고, Storybook으로 컴포넌트 카탈로그를 관리하고 싶습니다.
- E2E 테스트를 Playwright로 자동화하여, UI 회귀를 CI/CD 파이프라인에서 자동 감지하고 싶습니다.

## 6. 팀원들에게 한마디

UI는 사용자가 처음 만나는 부분이라 늘 긴장했지만, Web Designer의 디자인 감각과 Backend의 안정적인 API 덕분에 좋은 결과물을 만들 수 있었습니다. Antigravity로 새로운 UI 개발 방식을 경험한 것도 귀중한 배움이었습니다. 특히 QA가 꼼꼼하게 크로스 브라우저 테스트를 해준 덕분에 안심하고 배포할 수 있었습니다. 다음에도 함께하고 싶은 팀입니다.
