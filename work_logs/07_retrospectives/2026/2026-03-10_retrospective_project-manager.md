# 프로젝트 회고 — Project Manager (PM)

**프로젝트**: Hybrid RAG Knowledge Platform 고도화
**기간**: 2026-01-10 ~ 2026-03-10
**역할**: Sprint 관리, Jira/Slack 상태 관리, 팀 조율, 백로그 관리

---

## 1. 내가 기여한 것 (What I Did)

- **10개 Sprint 관리**: Sprint 01~10을 계획하고 실행하며, 약 60개 Story를 조율하여 프로젝트 목표 달성률을 높였습니다.
- **Jira 이슈 관리**: SCRUM-10부터 SCRUM-121까지 112개 이슈의 생성, 상태 전이(To Do -> In Progress -> Done), 우선순위 조정을 관리했습니다.
- **Slack 커뮤니케이션 허브**: proj-hrkp-dev, proj-hrkp-standup 채널을 통해 팀 전체의 소통 중심 역할을 수행했습니다. 매일 스탠드업 미팅을 진행하고 기록을 남겼습니다.
- **백로그 동기화**: Sprint 문서, Story 파일, Jira 상태의 3중 동기화 체계를 구축하고 운영했습니다. backlog-sync.sh 스크립트를 표준화하여 상태 불일치를 방지했습니다.
- **에이전트 작업 할당**: 13명의 에이전트에게 작업 유형에 맞는 Story를 할당하고, 의존성을 고려한 실행 순서를 조율했습니다.

## 2. 잘된 점 (What Went Well)

- **Sprint Velocity 안정화**: Sprint 03 이후로 Velocity가 안정적으로 유지되었고, 팀이 리듬을 찾아 예측 가능한 속도로 작업을 진행할 수 있었습니다.
- **팀 커뮤니케이션**: Slack 채널 체계(dev/standup/alerts/general)를 잘 분리하여 정보 과부하 없이 필요한 소통이 이루어졌습니다. 블로커 발생 시 30분 이내 에스컬레이션이 가능했습니다.
- **역할 분담 명확화**: v2.19에서 "PM은 조율하고, 개발자가 구현한다" 원칙을 확립한 후, 역할 혼선 없이 효율적으로 운영되었습니다.

## 3. 아쉬운 점 (What Could Be Better)

- **초기 PM 직접 코딩 사례**: 프로젝트 초기에 API Gateway 설정을 직접 수정하는 역할 위반이 있었습니다. 이 경험으로 역할 분담 원칙이 강화되었지만, 처음부터 지켰어야 합니다.
- **Story 추정 정확도**: 일부 Story의 Story Point 추정이 부정확하여 Sprint 중반에 스코프 조정이 필요한 경우가 있었습니다. 추정 기법을 개선할 필요가 있습니다.
- **다중 에이전트 병렬 작업 조율**: 3개 이상의 에이전트가 동시에 작업할 때 의존성 충돌이 발생한 적이 있었고, 더 세밀한 의존성 그래프 관리가 필요했습니다.

## 4. 배운 점 (What I Learned)

- **역할 분리의 중요성**: PM이 코드를 직접 만지면 품질도 떨어지고 관리도 소홀해집니다. "조율자"로서의 역할에 집중하는 것이 팀 전체 생산성에 훨씬 기여합니다.
- **자동화의 가치**: backlog-sync.sh 같은 도구가 수동 작업의 실수를 줄이고, 상태 동기화의 신뢰성을 높여준다는 것을 체감했습니다.
- **데일리 스탠드업의 힘**: 매일 15분 스탠드업이 블로커를 조기 발견하고 팀 사기를 유지하는 데 핵심적이었습니다.

## 5. 다음 프로젝트에 바라는 점

- Sprint Retrospective를 Sprint 종료마다 정기적으로 진행하여, 프로세스 개선을 지속적으로 반영하고 싶습니다.
- 자동화된 Sprint 대시보드(Burndown Chart, Velocity Chart)를 도입하여 진행 상황을 실시간으로 시각화하고 싶습니다.

## 6. 팀원들에게 한마디

2개월간 함께 달려와 주신 모든 팀원분들께 진심으로 감사드립니다. 13명이 각자의 전문성을 발휘하며 하나의 플랫폼을 만들어낸 이 경험은 정말 소중합니다. Sprint 01에서 빈 Docker Compose 파일로 시작해 18개 컨테이너가 유기적으로 동작하는 시스템을 완성한 여정, 잊지 못할 것입니다. 다음 프로젝트에서도 이 팀과 함께하고 싶습니다. 모두 수고하셨습니다!
