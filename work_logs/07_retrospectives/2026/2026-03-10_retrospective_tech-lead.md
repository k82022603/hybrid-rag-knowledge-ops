# 프로젝트 회고 — Tech Lead (TL)

**프로젝트**: Hybrid RAG Knowledge Platform 고도화
**기간**: 2026-01-10 ~ 2026-03-10
**역할**: 아키텍처 검토, 코드 리뷰, 기술 의사결정, ADR 관리

---

## 1. 내가 기여한 것 (What I Did)

- **상세 설계서 v2.4 검토 및 승인**: Hybrid RAG 4채널 아키텍처, API 통합 설계, 백엔드/인프라/Observability 설계서 등 14개 설계서를 기술적으로 검토하고 피드백을 제공했습니다.
- **소스코드 리뷰**: 전체 코드베이스에 대한 종합 리뷰를 수행하여 72.5/100 (B+) 점수를 산출하고, 모듈별 개선 사항을 구체적으로 제시했습니다.
- **ADR 관리**: DeepSeek V3.2 LLM 선정, BGE-M3 임베딩 모델 채택, Docker Compose 단일 호스트 전략, Reranker 1-Pass 확정 등 주요 기술 의사결정을 문서화했습니다.
- **Nori 미적용 사고 대응**: 32일간 미발견된 ES Nori 플러그인 누락 사고의 근본 원인을 분석하고, "설계서에 적혀 있다고 구현된 것이 아니다" 원칙을 수립했습니다.
- **모델 티어링 설계**: Opus 4.6과 Sonnet 4.6의 역할별 배분을 설계하여 73% 비용 절감을 달성했습니다.

## 2. 잘된 점 (What Went Well)

- **기술 부채 조기 식별**: 코드 리뷰를 통해 Reranker 이중 실행, Graph RRF 후보 수 이슈 등을 사전에 발견하고 수정할 수 있었습니다. 특히 Reranker 2-Pass가 수학적으로 중복임을 증명하여 성능 개선에 기여했습니다.
- **설계-구현 일관성 검증 문화**: Nori 사고 이후 "E2E 동작 확인" 원칙을 팀 전체에 내재화하여, 이후에는 설정 누락 사고가 재발하지 않았습니다.
- **RAGAS Mean 0.763 달성**: 아키텍처 레벨에서 4채널 Hybrid 융합(Dense + Sparse + Graph + Temporal)의 균형을 잡아, 역대 최고 성능을 이끌어냈습니다.

## 3. 아쉬운 점 (What Could Be Better)

- **Nori 미적용 32일 미발견**: 3차례 코드 리뷰에서 실동작 검증 없이 "OK"를 판정한 것은 TL로서 가장 큰 실책입니다. 코드와 설정 파일만 보고 판단하는 습관이 위험하다는 것을 뼈저리게 느꼈습니다.
- **코드 리뷰 시점**: 대규모 PR이 쌓인 후 한꺼번에 리뷰하는 경향이 있었습니다. 더 작은 단위로 자주 리뷰했으면 피드백 반영이 빨랐을 것입니다.

## 4. 배운 점 (What I Learned)

- **"Trust but Verify"**: 설계서와 코드가 일치한다고 가정하지 말고, 반드시 실행 결과로 검증해야 합니다. `_analyze` API 호출 한 번이면 확인할 수 있었던 것을 32일간 놓쳤습니다.
- **Cross-encoder의 수학적 특성**: Reranker가 query+content만으로 점수를 매기므로, 동일 입력에 대해 2-Pass는 1-Pass와 동일한 결과를 반환합니다. 이론적 분석이 실무 최적화에 직결됩니다.
- **비용 최적화와 품질의 균형**: 모델 티어링으로 73% 비용을 절감하면서도 품질 저하 없이 운영할 수 있음을 확인했습니다.

## 5. 다음 프로젝트에 바라는 점

- 자동화된 E2E 검증 파이프라인을 CI/CD에 통합하여, 설정 변경이 실제로 적용되었는지 배포 시점에 자동 검증하고 싶습니다.
- PR 크기 제한(500줄 이하)과 리뷰 SLA(24시간 이내)를 도입하여 리뷰 품질을 높이고 싶습니다.

## 6. 팀원들에게 한마디

기술적으로 도전적인 프로젝트였습니다. Dense + Sparse + Graph + Temporal 4채널을 융합하는 Hybrid RAG 아키텍처를 실현한 것은 팀 전원의 역량이 합쳐진 결과입니다. Nori 사고는 아프지만, 그 교훈이 팀의 엔지니어링 문화를 한 단계 끌어올렸다고 생각합니다. Architect가 설계하고, Developer가 구현하고, QA가 검증하는 이 사이클이 잘 돌아간 프로젝트였습니다.
